# React Notes App (AWS Amplify)

A simple React notes app backed by AWS Amplify (Auth + AppSync GraphQL API). This repo is intentionally part “learning project” and part working reference for a typical Amplify workflow.

## What’s in here

- **Frontend:** React (Create React App) + Amplify UI React
- **Auth:** Amplify Auth (Cognito)
- **API/Data:** Amplify GraphQL API (AppSync) with a `Note` model (includes `priority`)

## Quick start

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Common commands

- Dev server: `npm start`
- Tests: `npm test`
- Production build: `npm run build`

## Amplify workflow (recommended)

- **Sync cloud → local (pull backend config / Studio UI updates):** `amplify pull`
- **Deploy local backend changes (schema/auth/functions/etc):** `amplify push`
- **See what Amplify thinks changed:** `amplify status`

### When to run what

- **Frontend-only changes** (React code in `src/`, CSS, etc.)
	- Commit + push to GitHub; Amplify Console builds/deploys the frontend (if CI/CD is connected).

- **Backend changes** (anything under `amplify/`, like GraphQL schema)
	- Run `amplify push` (updates cloud backend and regenerates artifacts), then commit + push so the repo matches what’s deployed.

## Generated code notes (avoid surprises)

- `src/graphql/` is generated based on your GraphQL schema.
- `src/ui-components/` is generated by Amplify Studio and can be overwritten by `amplify pull`.
	- Prefer customizing Studio components via props/`overrides` from your own components instead of editing generated files directly.
